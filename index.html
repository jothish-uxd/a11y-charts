Charts that explain themselves.

Chart components that work beyond sight. Every chart ships with a plain-language summary, keyboard access, its own texture for every category, and a real data table, without extra work on your side.

Quick start

Point a chart at an element and give it a title and data. Summary, table, labels, and keyboard support are generated for you.

main.js
import { barChart } from "accessible-charts";
import "accessible-charts/styles.css";

barChart(document.querySelector("#chart"), {
  title: "Support tickets by channel",
  unit: "tickets",
  data: [
    { label: "Email", value: 412 },
    { label: "Chat", value: 286 },
    { label: "Phone", value: 97 },
  ],
});

What every chart includes

A generated summary
A plain-language takeaway sits before the table, so nobody has to inspect every value to get the point.
Keyboard access
Every mark can be focused. Focus shows the same tooltip and highlight that hover does.
Named marks
Each bar, slice, segment, and point has a full spoken name: category, value, share, and context.
A semantic table
The same data in a real table with row headers and right-aligned numbers.
Pattern, not color
Every mark is told apart by its pattern alone, so charts hold up in print, in grayscale, and for every kind of color vision.
Sensible reading order
Title, summary, chart, legend, then table: the order a screen reader meets them.
Light, dark, and high contrast
Chart text and surfaces follow your theme, and Windows High Contrast gets system colors.
Reduced motion
Transitions switch off when the operating system asks for less motion.

Donut

Part-to-whole composition. When readers need to compare similar values precisely, a bar chart is easier to read.

Usage

Proposed API. The package isn't on npm yet; this is the interface the extracted library will expose.

donut.js
import { donutChart } from "accessible-charts";
import "accessible-charts/styles.css";

const data = [
  { label: "Rebel / Resistance, non-Jedi", value: 9 },
  { label: "Imperial officer / trooper", value: 6 },
  { label: "Rebel / Resistance Jedi", value: 5 },
  // …one object per slice
];

donutChart(document.querySelector("#groups"), {
  title: "Star Wars character groups",
  unit: "characters",
  data,
  centerLabel: "Total characters", // shows the sum in the hole
});

Options

Options
OptionTypeDescription
titlestringRequired. Accessible name for the chart; also used as the SVG <title>.
dataArrayRequired. See the data shape above.
centerLabelstring | falseText above the total in the center. false hides the center label.
sortbooleanOrder slices largest first. Defaults to false so your order is kept.
unitstringNoun used in labels and summaries, for example "characters". Defaults to "items".
summary"auto" | string | falsePlain-language summary placed before the table. "auto" generates one from the data.
tablebooleanRender the semantic data table. Defaults to true. Turn off only if the same data is shown elsewhere on the page.
patternsstring[]Override the default pattern sequence, for example to keep a category's pattern consistent across charts.

Built-in accessibility

  • Each slice is a focusable mark whose name gives the category, count, and share of the total.
  • Slices are separated by a gap and carry a distinct pattern, so they can be told apart without color.
  • The center total is decorative; the same number is in the summary and table.
  • Focus and hover both dim the other slices and open the same tooltip.

Horizontal bars

Ranked comparison across categories. Labels get their own space, so long category names are never truncated.

Usage

Proposed API. The package isn't on npm yet; this is the interface the extracted library will expose.

bar.js
import { barChart } from "accessible-charts";
import "accessible-charts/styles.css";

const data = [
  { label: "Rebel / Resistance, non-Jedi", value: 9 },
  { label: "Imperial officer / trooper", value: 6 },
  // …one object per bar
];

barChart(document.querySelector("#ranking"), {
  title: "Character groups by count",
  unit: "characters",
  data,
  orientation: "horizontal",
  axisMax: 20,
});

Options

Options
OptionTypeDescription
titlestringRequired. Accessible name for the chart; also used as the SVG <title>.
dataArrayRequired. See the data shape above.
orientation"horizontal" | "vertical"Bar direction. Defaults to "horizontal".
axisMaxnumberFixed upper bound for the value axis. Defaults to the rounded-up maximum.
sortbooleanRank bars largest first. Defaults to true.
unitstringNoun used in labels and summaries, for example "characters". Defaults to "items".
summary"auto" | string | falsePlain-language summary placed before the table. "auto" generates one from the data.
tablebooleanRender the semantic data table. Defaults to true. Turn off only if the same data is shown elsewhere on the page.
patternsstring[]Override the default pattern sequence, for example to keep a category's pattern consistent across charts.

Built-in accessibility

  • Each bar's name includes its rank, so position in the list carries meaning when heard.
  • Values are printed beside the bar, so they never sit on top of a pattern.
  • The data table adds a rank column that matches the visual order.

Multi-line

Compare trends, peaks, and timing across series over time.

Usage

Proposed API. The package isn't on npm yet; this is the interface the extracted library will expose.

line.js
import { lineChart } from "accessible-charts";
import "accessible-charts/styles.css";

const periods = ["Episode I", "Episode II", "Episode III" /* … */];

const series = [
  { label: "Rebels", values: [18, 24, 31, 52, 68, 74, 61] },
  { label: "Empire", values: [34, 38, 52, 46, 58, 49, 43] },
  { label: "Independent", values: [12, 18, 24, 32, 40, 47, 55] },
];

lineChart(document.querySelector("#activity"), {
  title: "Faction activity by saga period",
  unit: "activity score",
  categories: periods,
  series,
});

Options

Options
OptionTypeDescription
titlestringRequired. Accessible name for the chart; also used as the SVG <title>.
dataArrayRequired. See the data shape above.
categoriesstring[]Required. Labels for the x-axis, in order.
seriesArrayRequired. Replaces data for this chart; one entry per line.
unitstringNoun used in labels and summaries, for example "characters". Defaults to "items".
summary"auto" | string | falsePlain-language summary placed before the table. "auto" generates one from the data.
tablebooleanRender the semantic data table. Defaults to true. Turn off only if the same data is shown elsewhere on the page.
patternsstring[]Override the default pattern sequence, for example to keep a category's pattern consistent across charts.

Built-in accessibility

  • Series are told apart by dash style, marker shape (circle, square, triangle), and filled versus hollow markers.
  • Each point's name includes the change from the previous period, so trends can be followed by ear.
  • Focusing a point dims the other series to make the active line easy to trace.

Spiral graph

Wrap a timeline into a spiral, one turn per year, so the same month lines up across years and seasonal patterns show.

Usage

Proposed API. The package isn't on npm yet; this is the interface the extracted library will expose.

spiral.js
import { spiralGraph } from "accessible-charts";
import "accessible-charts/styles.css";

// One value per month, oldest first. Each turn of the spiral is one year.
const data = [
  { period: "2023-01", value: 13 },
  { period: "2023-02", value: 13 },
  // …one object per month
];

spiralGraph(document.querySelector("#visits"), {
  title: "Monthly cantina visits",
  unit: "thousand visits",
  data,
  cycle: 12,             // points per turn
  cycleLabel: "Year",    // read as "July, Year 3"
});

Options

Options
OptionTypeDescription
titlestringRequired. Accessible name for the chart; also used as the SVG <title>.
dataArrayRequired. One { period, value } per point, oldest first.
cyclenumberPoints per turn of the spiral. Defaults to 12 (months in a year); use 7 for days of the week or 24 for hours of the day.
cycleLabelstringWhat one turn is called in labels, for example "Year" or "Week".
labelsstring[]Names for the positions around the spiral. Defaults to month names when cycle is 12.
unitstringNoun used in labels and summaries, for example "thousand visits".
summary"auto" | string | falsePlain-language summary placed before the table. "auto" describes growth across turns, where each turn peaks and dips, and the biggest break in the pattern.
tablebooleanRender the semantic table, with positions in rows and turns in columns. Defaults to true.

Built-in accessibility

  • The whole chart is one Tab stop. Left and Right arrows move by month, Up and Down move to the same month in the previous or next year, and Home and End jump to the first and last month.
  • Each bar's name gives the month, the year, the value, and the change from the same month a year earlier, so seasonal patterns and growth can both be followed by ear.
  • Focusing a bar highlights the same month in every year, so a month can be compared across turns of the spiral at a glance.
  • Without the arrow keys, for example in a screen reader's reading mode, every bar can still be read one after another in time order.
  • The table matches how the spiral is read: months in rows, years in columns, and a total for each year.

Arc diagram

Show who connects to whom along a single line, and how strong each connection is.

Usage

Proposed API. The package isn't on npm yet; this is the interface the extracted library will expose.

arc.js
import { arcDiagram } from "accessible-charts";
import "accessible-charts/styles.css";

const nodes = [
  { id: "luke", label: "Luke Skywalker", short: "Luke", group: "Rebels" },
  { id: "vader", label: "Darth Vader", short: "Vader", group: "Empire" },
  // …one object per node
];

const links = [
  { source: "luke", target: "vader", value: 6 },
  // …one object per connection
];

arcDiagram(document.querySelector("#scenes"), {
  title: "Characters who share scenes",
  unit: "shared scenes",
  nodes,
  links,
  order: "group", // keep each group together along the line
});

Options

Options
OptionTypeDescription
titlestringRequired. Accessible name for the chart; also used as the SVG <title>.
nodesArrayRequired. One { id, label, short, group } per node. short is the name drawn under the node; label is read aloud.
linksArrayRequired. One { source, target, value } per connection. value sets the arc's thickness.
unitstringWhat a link's value counts, for example "shared scenes". Read with every connection.
order"group" | "input" | "connections"Node order along the line. "group" keeps groups together; "connections" puts the most connected first. Defaults to "group".
summary"auto" | string | falsePlain-language summary placed before the table. "auto" names the most connected node, the strongest pair, and how many links cross groups.
tablebooleanRender the semantic table of connections. Defaults to true. Turn off only if the same data is shown elsewhere on the page.
shapesstring[]Override the marker order for groups. Defaults to hollow circle, filled square, hollow triangle, then further shape and fill combinations.

Built-in accessibility

  • Each character is focusable, and its name says how many connections it has and lists them strongest first, so the network can be explored one character at a time.
  • Focusing a character dims every arc that isn't theirs, so its connections stand out from the rest.
  • Arc thickness shows the number of shared scenes, and solid versus dashed shows whether a connection stays inside a faction or crosses factions. Both are also in the names and the table.
  • Factions are told apart by marker shape and fill, and labelled under the line.
  • The table lists every connection, strongest first, and the summary names the most connected character, the strongest pair, and who bridges factions.

Scatter plot

Show how two measures move together, and which points break the pattern.

Usage

Proposed API. The package isn't on npm yet; this is the interface the extracted library will expose.

scatter.js
import { scatterPlot } from "accessible-charts";
import "accessible-charts/styles.css";

const data = [
  { label: "Red Two", group: "Rebels", x: 60, y: 48 },
  { label: "Black Two", group: "Empire", x: 80, y: 44 },
  { label: "Kestrel", group: "Independent", x: 45, y: 82 },
  // …one object per point
];

scatterPlot(document.querySelector("#pilots"), {
  title: "Training hours and mission success",
  unit: "pilots",
  data,
  x: { label: "Training hours", unit: "hours" },
  y: { label: "Mission success", unit: "%" },
  trendLine: true, // adds a line of best fit and "above / below trend" in every label
});

Options

Options
OptionTypeDescription
titlestringRequired. Accessible name for the chart; also used as the SVG <title>.
dataArrayRequired. One { label, group, x, y } per point. group is optional.
x{ label, unit }Required. Names the horizontal measure. The label titles the axis and is read with every point.
y{ label, unit }Required. Names the vertical measure, read the same way.
trendLinebooleanDraw a line of best fit and say how far each point sits above or below it. Defaults to true.
unitstringNoun for the points in labels and summaries, for example "pilots". Defaults to "points".
summary"auto" | string | falsePlain-language summary placed before the table. "auto" states the direction and strength of the relationship and names the biggest exception.
tablebooleanRender the semantic data table. Defaults to true. Turn off only if the same data is shown elsewhere on the page.
shapesstring[]Override the marker order for groups. Defaults to hollow circle, filled square, hollow triangle, then further shape and fill combinations.

Built-in accessibility

  • Each point's name gives its group, both values with their units, and how far it sits above or below the trend, so the shape of the data can be followed by ear.
  • Groups are told apart by marker shape and by filled versus hollow markers, never by color alone.
  • The summary states the direction and strength of the relationship in plain words, and names the biggest exception.
  • The table lists every point with its distance from the trend, so exceptions stand out without reading the chart.
  • Both axes are titled with their units, and focusing a point dims the other groups so it is easy to find.
