# Automated accessibility audit

Generated by `npm run audit` on 2026-11-10 for accessible-charts v0.2.1. Do not edit the part above the marker near the end; re-run the script instead.

**Result: all automated checks pass.** 26 page states checked with axe-core (0 violations expected), and 12 charts put through 11 scripted checks each.

Automated checks find only a portion of accessibility problems. They cannot judge whether a summary is useful or how a chart sounds in a screen reader. See the [accessibility statement](../ACCESSIBILITY.md) for what has not been tested.

## Reviewed by hand

The "needs review" elements were checked by a person reading the computed colors. All of them are one of these:

| What axe flagged | Why it could not decide | Checked result |
| --- | --- | --- |
| Chart text inside the SVG: axis ticks, labels, values, the donut's center text | axe cannot work out the background behind SVG text | Labels and values use the ink color: 17.9:1 on light, 16.9:1 on dark. Ticks and the center caption use the soft ink: 5.7:1 on light, 7.7:1 on dark. All pass AA (4.5:1). |
| Labels drawn on top of a texture (sunburst rings, spiral years) | The text sits over a pattern | Each label has a 6 px halo in the background color, so it is read against the background, not the pattern: same ratios as above. |
| Arrow keycaps in the keyboard hint, and single symbols in the page chrome | The content is a symbol, not words | Ink color on the background: 17.9:1 light, 16.9:1 dark. |

## What this audit does not cover

- Screen readers, voice control, switch access, touch.
- Using the charts by hand in Firefox or Safari. WebKit under test automation is close to Safari, not the same.
- Windows High Contrast, 200% and 400% zoom, text-spacing overrides.
- The dimmed state of unfocused marks, and anything else that only appears while interacting, beyond the keyboard checks above.
- `examples/index.html`. It renders the same package code as the docs site's live examples.

The scripted focus-ring check compares against the light theme's focus color only.
